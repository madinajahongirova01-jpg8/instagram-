# SPEC: Feed и Explore

Модули NestJS: `feed` · Swagger: `/api/docs`

## Функциональность

Лента публикаций и раздел «Интересное».

Источник: `GET /api/posts/feed` (20 постов без пагинации) и `GET /api/explore` — перенесены с курсорной пагинацией и исправленной сортировкой.

## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/feed` | Посты свои + подписок, без архивных и без заблокированных, `createdAt desc, id desc`. Пагинация: `?cursor=<id>&limit=1..50` → `{ items, nextCursor }`. |
| GET | `/api/feed/explore` | За последние дни: популярные посты (30) и reels (20) от неподписанных, тренды хэштегов (20), рекомендации пользователей |

## DTO

`PaginationQueryDto { cursor?, limit? }`. Ответ ленты — `Paginated<PostDto>`.

## Связи с другими модулями

**Базовый алгоритм:** лента — хронологическая; explore — сортировка по числу лайков, затем комментариев/просмотров, затем по дате. Персонализация — в ROADMAP. Зависит от `posts` (формирование `PostDto`), `privacy`.
