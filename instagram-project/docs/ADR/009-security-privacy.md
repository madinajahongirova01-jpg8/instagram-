# ADR-009: Безопасность и приватность

**Статус:** принято · **Дата:** 2026-10-23

## Проблема

Исходник: нет rate limit, Helmet, проверки владельца, проверки приватности; regex-инъекция в поиске; уведомления можно создавать любому.

## Рассмотренные варианты

Проверки в каждом контроллере вручную либо **централизованные сервисы + глобальные guards/pipes**.

## Принятое решение

- **Helmet**, отключён `x-powered-by`, CORS только для `WEB_ORIGIN` с `credentials`.
- **Rate limiting**: `@nestjs/throttler` глобально (`THROTTLE_LIMIT` в минуту), строже на auth (10/мин, forgot-password 5/мин).
- **Валидация**: `whitelist` + `forbidNonWhitelisted` — лишние поля отклоняются (защита от mass assignment).
- **Владелец ресурса**: изменение/удаление поста, story, reel, медиа — только автор; комментарий удаляет автор или владелец поста; сообщение — отправитель.
- **Приватность** (`VisibilityService`): блокировка в любую сторону скрывает контент; приватный аккаунт виден только подписчикам; настройки `allowComments`, `allowMentions`, `allowDirectMessages`, `allowTagging` (`EVERYONE` / `FOLLOWERS` / `NO_ONE`), `showOnlineStatus`, `showReadReceipts`.
- **Медиа**: проверка сигнатуры файла (magic bytes), белый список MIME, лимиты (изображение 10 МБ, видео 100 МБ, аудио 10 МБ), Sharp поворачивает по EXIF, уменьшает и пересжимает изображения в JPEG без метаданных (EXIF, включая GPS, не сохраняется). Ссылки подписываются HMAC и истекают; перед выдачей ссылки проверяется доступ к контенту.
- **Логи**: pino с `redact` для `authorization`, `cookie`, `set-cookie`, полей с паролями и токенами.
- **Ошибки**: 5xx не раскрывают детали; ответ на forgot-password одинаков для существующих и несуществующих email.
- Уведомления создаются только сервером.

## Причины выбора

Централизация уменьшает шанс забыть проверку в новом endpoint.

## Последствия

- Проверка email при регистрации отвечает 409, если email занят: это компромисс ради понятного UX, защищён строгим rate limit.
- Подписанная ссылка на медиа живёт 1–2 часа: если доступ отозван, уже выданная ссылка работает до истечения.
