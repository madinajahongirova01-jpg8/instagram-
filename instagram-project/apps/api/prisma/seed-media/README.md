# Файлы для демо-данных

Эта папка не попадает в git (кроме этого README). Положите сюда свои файлы и запустите `npm run db:seed` из корня проекта.

| Папка | Что положить | Для чего |
|---|---|---|
| `videos/` | `.mp4` (лучше), `.webm` или `.mov` | Каждый файл → отдельный Reel (одно видео ещё станет story) |
| `images/` | `.jpg`, `.png`, `.webp` | Посты (часть — карусели по 2–5 фото) и stories |
| `avatars/` | `.jpg`, `.png`, `.webp` (необязательно) | Аватары демо-пользователей по порядку имён файлов |

Где брать видео и фото бесплатно:

- https://www.pexels.com/videos/ и https://pixabay.com/videos/ — ищите «Dushanbe», «Tajikistan», «mountains», «city night».
- https://www.pexels.com/ и https://pixabay.com/ — фото.

Рекомендации для видео:

- вертикальные (9:16), до 20 секунд, 720p (файл «HD 720» / «SD»), размер до 100 МБ (лучше до 15 МБ);
- 3–6 видео достаточно.

Рекомендации для фото: 8–20 штук, до 10 МБ каждое. Файлы берутся по алфавиту, так что порядок можно задать именами (`01.jpg`, `02.jpg`, …).

Если `images/` пустая, seed нарисует простые картинки-пейзажи. Если `videos/` пустая, reels не создаются — seed просто напишет об этом.
